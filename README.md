# 정희주에 관한 사실(작성자가 직접 보고 적어봄...)
정희주는 문을 열지 않는다. 문이 정희주에게 길을 비켜준다.

정희주는 늦은 적이 없다. 시간이 정희주를 기다린다.

정희주는 커피를 마시지 않는다. 커피가 정희주를 마신다.

정희주는 엘리베이터를 타지 않는다. 건물이 정희주를 따라 내려간다.

정희주는 길을 잃지 않는다. 지도가 정희주를 찾는다.

정희주는 질문에 답하지 않는다. 답이 정희주에게 질문한다.

정희주는 회의에 들어가지 않는다. 회의가 정희주 안으로 들어온다.

정희주는 비밀번호를 입력하지 않는다. 시스템이 정희주를 알아본다.

정희주는 야근을 하지 않는다. 하루가 정희주의 퇴근 시간에 맞춰 늘어난다.

정희주는 실수를 하지 않는다. 오류 메시지가 사과한다.
